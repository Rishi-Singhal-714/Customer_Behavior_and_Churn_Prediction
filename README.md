# Customer Churn Prediction

Predict which customers will leave and get business insights to reduce churn.

## 📊 Results
- **Accuracy**: 85.06%
- **Churn Rate**: 56.8%
- **Top Predictor**: Payment Delay
- **Potential Savings**: $84M/year

## 🚀 Quick Start

### Google Colab:
1. Upload `customer_churn.ipynb` to Cola
2. Upload `customer_churn.csv` when prompted
3. Run all cells

### Files:
customer_churn.ipynb - Complete analysis notebook
customer_churn.csv - Dataset (516K customers)
churn_model.pkl - Trained model
